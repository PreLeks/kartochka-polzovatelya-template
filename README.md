# Карточка пользователя

## О проекте
Минималистичная HTML/CSS карточка профиля для демонстрации данных пользователя: имя, должность и кнопка контакта. Проект представляет собой статический шаблон, созданный как задание по верстке.

## Функционал
- Отображение аватара, имени и должности пользователя.
- Кнопка вызова действия "Написать".
- Темный карточный интерфейс с мягкими скруглениями и hover-эффектом.
- Готовая адаптивная верстка на чистом HTML/CSS.

## Структура проекта
- `index.html` — разметка карточки пользователя.
- `css/style.css` — стили интерфейса и визуальное оформление.
- `img/avatar.png` — изображение аватара.
- `fonts/InterRegular.woff2` — шрифт Inter.
- `verstaem.json` — метаданные задания.

## Технологический стек
- HTML5
- CSS3
- Сборка отсутствует: проект статический
- Шрифт: Inter
- Дополнительно: локальные ресурсы (`img`, `fonts`)

## Запуск
В проекте нет `package.json`, поэтому установка зависимостей не требуется.

Способы запуска:
1. Откройте файл `index.html` в браузере.
2. Или запустите локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

После этого откройте в браузере адрес:

```text
http://localhost:8000
```

## Цель
Шаблон карточки пользователя для верстки и визуального оформления профиля без использования JavaScript и фреймворков.
